# ARENA / BATTLE LAB

팀을 편성해 CPU와 싱글·더블 배틀을 하는 React + TypeScript + Vite 게임입니다. 전투 데이터와 이벤트 재생은 구현되어 있습니다. **캐릭터 이미지 라이브러리는 미완성**이며 이 배포본에 실제 포켓몬 스프라이트는 포함되어 있지 않습니다. 완성된 그래픽 버전으로 오인하지 않도록 시작 화면과 설정에서 준비 상태를 표시합니다.

## 실행과 검사

Node.js 22.12 이상 또는 24 이상이 필요합니다.

```bash
npm ci
npm run dev
```

터미널에 표시되는 주소(기본 http://127.0.0.1:5173)를 여세요.

```bash
npm test                    # 전투, 이벤트, 순차 재생, 180종, 팀, UI 테스트
npm run test:browser         # 실제 Chrome/Edge: 편성·5턴·모션·교체·더블·모바일
npm run test:choice          # 실제 Chrome/Edge: 구애 기술 고정·교체 후 해제
npm run test:conditions      # 실제 Chrome/Edge: 이상한빛·혼란 표시·기절 후 출전
npm run test:assets          # 직접 만든 진단용 PNG로 이미지 가져오기/오류/저장 검사
npm run assets:check         # 실제 public/sprites 커버리지; 미완성이면 종료 코드 1
npm run build
npm run preview
```

브라우저 검사는 설치된 Chrome/Edge를 사용합니다. 자동 검색되지 않으면 `CHROME_PATH` 환경 변수를 설정하세요. 캡처와 검사 보고서는 `work/`에 저장됩니다. Vitest는 Windows의 분리된 프로세스 간 임시 캐시 파일 문제를 피하도록 threads pool을 사용합니다.

## 구현된 데이터와 편성

- 실제 전국도감 번호가 서로 다른 **180종**, **18개 대표 타입에 정확히 10종씩**. 복합 타입은 실제 두 타입을 유지합니다.
- Showdown의 종족값·타입·가능한 특성과 학습 목록, PokeAPI의 한국어 이름을 변환한 정적 데이터입니다. 원문 파일 해시와 선택표는 `docs/data-sources.json`, 종별 원문 대조 자료는 `docs/roster-evidence.json`에 있습니다.
- 63개 구현 기술과 각 종의 실제 학습 목록의 교집합을 제공합니다. 한 종당 최소 7개이며 이름만 있는 빈 항목은 없습니다. 이전 진화 단계에서 배운 기술을 포함하는 세대 통합 규칙입니다. 특정 공식 대회에서의 동시 습득 가능성까지 검사하지는 않습니다.
- 이름·영문 ID 검색, 대표 타입 필터, 여섯 종족값 확인, 추가·제거·교체, 기술 4개, 실제 가능한 특성, 도구, 성격, IV·EV 설정, 저장·불러오기와 배틀 전 검증을 제공합니다.
- 팀은 1~6마리(더블은 최소 2마리)이고 중복 종·중복 기술·학습 목록 밖 기술·잘못된 특성·EV 초과를 검사합니다. 편성한 팀의 설정이 실제 전투에 쓰입니다.
- 특성 데이터와 엔진 지원은 별개입니다. 구현되지 않은 특성은 편성 설명에서 **효과 미지원**으로 명시합니다. 기본 공격력 보정·날씨·위협·면역·정전기·까칠한피부·철가시 등의 선언형 효과를 지원합니다.

## 추가로 연결한 특성과 지닌 도구

- 축전·저수는 해당 타입 기술을 무효화하고 HP 1/4을 회복합니다. 타오르는불꽃은 불꽃 공격을 흡수하면 교체 전까지 자신의 불꽃 공격을 강화합니다.
- 재생력은 교체 시 HP 1/3 회복, 천하장사·순수한힘은 공격 2배, 근성은 상태 이상 시 공격 1.5배 및 화상 감소 무시, 이상한비늘은 상태 이상 시 방어 1.5배입니다.
- 클리어바디는 외부 능력치 하락을 차단하고, 정신력은 위협을 차단합니다. 오기·승기는 상대의 실제 능력치 하락에 반응합니다. 싱크로는 화상·독·마비를 유발자에게 반사합니다.
- 복안, 모래숨기·눈숨기의 명중 보정과 하늘의은총의 확률형 부가 효과 보정을 지원합니다. 풀죽음도 지원하며 정신력이 이를 막습니다.
- 구애스카프·구애머리띠·구애안경의 능력치 보정과 기술 고정은 엔진·CPU·UI가 같은 규칙을 사용합니다. 교체하면 해제되고, 고정된 기술의 PP가 없으면 발버둥을 선택할 수 있습니다.
- 자뭉열매는 HP가 절반 이하가 되는 피해 직후 회복하고 소모됩니다. 기합의띠는 HP가 가득 찼을 때 직접 공격을 한 번 버팁니다. 생명의구슬은 피해 보정과 기술당 한 번의 반동을 적용합니다.
- 가방 메뉴에서 실제 지닌 도구와 소모 여부를 확인할 수 있습니다. HP 회복도 실제 이벤트 수치로 애니메이션을 재생합니다.

발동 조건은 Showdown 원문의 [특성](https://github.com/smogon/pokemon-showdown/blob/master/data/abilities.ts)과 [도구](https://github.com/smogon/pokemon-showdown/blob/master/data/items.ts)를 대조해 지원 범위 안에서 구현했습니다. 전체 엔진을 가져온 것은 아니므로 공식 엔진과 반올림·복합 효과의 세부 처리까지 동일하다고 보장하지 않습니다.

## 풀죽음·혼란·필드 확장

- 에어슬래시·아이언헤드·스톤샤워·악의파동·폭포오르기의 풀죽음은 대상이 아직 행동하지 않았을 때만 해당 턴의 기술을 막습니다. 턴 종료 시 해제되며 PP는 소모하지 않습니다.
- 물의파동·폭풍·이상한빛의 혼란은 주요 상태 이상과 함께 존재합니다. 1~4회의 행동 검사 동안 33% 확률로 자해하며 교체하면 해제됩니다. 자해는 종족 능력치와 랭크로 계산하고, 자속·급소·화상·공격 특성·지닌 도구 피해 보정은 적용하지 않습니다. 실제 HP 피해·기절·승패와 연결됩니다.
- 마이페이스는 혼란과 위협을 막고, 옹골참은 최대 HP에서 직접 공격을 버팁니다. 전투무장·조가비갑옷은 급소를 막고, 대운과 스톤에지·섀도클로·잎날가르기는 급소 단계를 올립니다.
- 비에서는 번개·폭풍이 필중이고 쾌청에서는 기본 명중률이 50입니다. 모래바람은 바위 타입의 특수방어, 눈은 얼음 타입의 방어를 1.5배로 높입니다.
- 미스트필드·사이코필드·모래바람·설경 기술을 추가했습니다. 사이코필드는 지면의 상대에 대한 우선도 공격을 막고, 그래스필드는 지면 대상의 지진 피해를 절반으로, 미스트필드는 지면 대상의 드래곤 피해를 절반으로 줄이며 혼란을 막습니다. 필드 회복·보정·상태 보호는 비행 및 부유를 판정합니다.
- 수면가루의 풀 타입 면역, 쾌청의 얼음 방지, 플레어드라이브 사용자의 해동과 불꽃 공격에 맞은 대상의 해동을 지원합니다.

처리 규칙은 [Showdown 상태 정의](https://github.com/smogon/pokemon-showdown/blob/master/data/conditions.ts), [기술 정의](https://github.com/smogon/pokemon-showdown/blob/master/data/moves.ts), [혼란 피해 계산](https://github.com/smogon/pokemon-showdown/blob/master/sim/battle-actions.ts)을 대조했습니다.

## 실제 전투 이벤트와 연출

`runTurnWithEvents`는 기존 엔진의 계산 과정에서 이벤트와 그 시점의 상태 복사본을 생성합니다. 최종 HP 차이를 보고 가짜 공격 이벤트를 만들지 않습니다. 기존 `runTurn` 결과와 이벤트 재생 후 결과가 일치하는지 테스트합니다.

1. 플레이어와 CPU의 행동을 정하고 우선도·스피드·시드 난수로 실행 순서를 결정합니다.
2. 기술, 실제 대상, 피해 전후 HP, 랭크 변화, 보호·빗나감, 특성·도구, 상태, 교체, 기절, 턴 종료를 순서대로 기록합니다.
3. UI가 이벤트 스냅샷을 표시하고 Web Animations API의 `finished`를 기다린 뒤 다음 이벤트로 이동합니다.
4. 퇴장 이벤트에는 기존 포켓몬이 남고, 등장 이벤트에서 새 포켓몬의 HP·상태·스프라이트를 불러옵니다. 기절 후에는 살아 있는 대기 포켓몬이 자동 출전합니다.
5. 모든 이벤트가 끝날 때까지 명령을 잠급니다. 중복 실행 방지용 동기 잠금, 취소 시그널, 렌더러 정지 감시와 실패 복구가 있습니다.

물리 공격의 이동과 타격, 특수 공격의 타입 색상 투사체, 피해 시 HP 변화·피격, 랭크 변화 오라, 보호막, 교체·기절 모션을 구현했습니다. CSS 변환과 Web Animations를 사용하는 연출이며 원본 게임의 프레임 애니메이션을 구현한 것은 아닙니다. 이미지가 없는 상태에서는 이름 표시에 모션이 적용됩니다.

CPU는 자신의 실제 기술과 예상 피해, 상태 및 교체 이득을 평가합니다. 교체 쿨다운으로 매 턴 반복 교체를 제한합니다. 명시적인 교체 행동이나 기절 교체가 없으면 활성 포켓몬은 그대로 유지됩니다.

## 이미지 라이브러리: 아직 해결되지 않은 항목

**실제 포켓몬 스프라이트: 정면 0/180, 후면 0/180.** 공식 그림의 재배포 권한을 확인하지 못해 이번 결과는 그래픽 완료 기준을 충족하지 못합니다. 정상 상태처럼 보이던 네모 대체 블록과 `스프라이트 미제공` 배지는 제거했습니다. 미완성 상태에서는 종 이름과 전국도감 번호를 표시하며 존재하지 않는 PNG 경로를 계속 요청하지 않습니다.

사용 권한이 있는 파일은 다음 두 경로로 연결할 수 있습니다.

- **설정 → 스프라이트 폴더 가져오기**: `front/25.png`, `back/25.png` 구조의 폴더를 가져옵니다. PNG 시그니처·실제 디코딩·크기·도감 번호를 검사하고 IndexedDB에 저장합니다. 브라우저를 다시 열어도 복원됩니다.
- **프로젝트에 포함**: 같은 구조로 `public/sprites/`에 놓고 `npm run assets:index`를 실행하면 실제 파일만 manifest에 등록합니다. 배포용 파일의 사용 권한과 출처를 함께 기록해야 합니다.

후면이 없거나 로딩에 실패하면 같은 종의 정면 경로로 재시도합니다. 두 경로 모두 없으면 미완성 상태로 돌아가며 전투는 유지됩니다. 이미지 가져오기 테스트는 직접 만든 진단용 그림만 사용합니다. 이 테스트의 성공을 실제 포켓몬 이미지 180종 검증으로 해석해서는 안 됩니다.

검토 결과와 출처: `docs/sprite-sources.md`, `THIRD_PARTY_NOTICES.md`.

## 지원 규칙과 남은 범위

레벨 50, 물리·특수 데미지, 18타입 상성·자속, 85~100% 변동, 기본 급소, 우선도·명중·회피·PP, 성격·IV·EV, 랭크, 화상·독·마비·잠듦·얼음, 연속 방어 성공률 감소, 날씨·필드 일부 효과, 교체, 승패를 지원합니다. 난수 상태가 전투 상태에 들어 있어 같은 시드와 행동으로 재현할 수 있습니다.

공식 Pokémon Champions 또는 Showdown 엔진 전체와 동일하지 않습니다. 온라인, 모든 특성·기술 효과, 테라스탈, 설치기, 다단 공격과 세대별 예외는 미지원입니다. 지면 판정은 비행 타입과 부유만 지원하며 중력·지면 관련 도구는 없고, 일부 날씨/필드 효과도 축소했습니다. 가방 소모품은 구현되어 있지 않으며 지닌 도구만 자동 적용됩니다.

## 주요 파일

- `src/data/roster.generated.ts`: 180종과 실제 가능한 특성 데이터
- `src/data/index.ts`: 구현 기술·특성·도구·상성
- `src/engine/events.ts`, `battle.ts`, `effects.ts`, `ai.ts`: 실제 이벤트 발생·턴·CPU
- `src/presentation/queue.ts`, `animate.ts`: 완료 신호를 기다리는 순차 재생과 모션
- `src/presentation/sprites.ts`, `src/components/PokemonArtwork.tsx`: 이미지 등록·영속 저장·대체 경로
- `src/App.tsx`, `src/styles.css`: 편성·도감·배틀·설정 UI
- `scripts/download-data.cjs`, `generate-roster.cjs`: `npm run data:refresh`로 원문 재다운로드/생성

데이터는 런타임에 외부 API를 호출하지 않습니다. Showdown의 코드 라이선스(MIT)와 PokeAPI의 BSD 고지는 `docs/licenses/`에 보존했습니다. 이름 및 상표는 각 권리자에게 속하며 공식 프로젝트가 아닙니다.
