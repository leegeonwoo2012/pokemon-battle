# ARENA / BATTLE LAB

포켓몬 팀을 편성해 CPU와 싱글·더블 배틀을 플레이하는 브라우저 게임입니다. 수집·탐험·온라인 대전은 포함하지 않습니다. 이 프로젝트는 **비공식 팬 제작 프로토타입**이며 공식 Pokémon Champions의 규칙을 재현한다고 주장하지 않습니다.

## 실행

Node.js 22.12 이상(또는 24 이상)과 npm이 필요합니다.

```bash
npm ci
npm run dev
```

터미널에 표시되는 로컬 주소(기본 `http://127.0.0.1:5173`)를 브라우저에서 여세요. 메인 화면에서 싱글 또는 더블 배틀을 시작할 수 있습니다. 팀 편성에서 포켓몬, 기술 4개, 특성, 도구, 성격, IV, EV를 바꾸고 브라우저에 저장하거나 불러올 수 있습니다.

```bash
npm test          # Vitest 자동 테스트
npm run test:browser  # Chrome/Chromium에서 화면·팀 저장·싱글·더블 흐름 검사
npm run build     # TypeScript 검사 후 dist/에 배포용 파일 생성
npm run preview   # 빌드 결과 로컬 확인
```

브라우저 검사는 설치된 Chrome 또는 Edge를 사용합니다. 자동 검색이 안 되면 `CHROME_PATH` 환경 변수에 실행 파일 경로를 지정하세요. 검사 화면 캡처는 `work/`에 저장됩니다.

## 현재 구현 범위

- React + TypeScript + Vite 반응형 UI: 메인 메뉴, 팀 편성, 포켓몬 목록, 설정, 배틀 화면과 로그, 승패 및 재대전.
- 직접 작성한 소규모 데이터: 포켓몬 **18종**, 기술 **57개**, 18타입 상성, 성격 25종, 도구 9종. 모든 포켓몬이나 기술을 수록한 도감이 아닙니다.
- 레벨 50 능력치 계산: 종족값·성격·IV(0~31)·EV(능력치별 0~252, 총합 510). 팀은 1~6마리이며 더블 배틀에는 최소 2마리가 필요합니다. 같은 종·같은 기술의 중복, 학습 목록 밖 기술 등은 검사합니다.
- 전투: 물리·특수 데미지, 타입 상성, 자속, 85~100% 데미지 변동, 급소(기본 1/24 확률·1.5배), 명중·회피, 우선도·스피드, PP와 발버둥, 능력치 단계, 화상·독·마비·잠듦·얼음, 교체와 등장 시 효과, 기절·승패 판정.
- 더블 배틀: 각 포켓몬의 행동과 단일 대상 지정, 적 전체·사용자 제외 전체 범위 기술, 범위 데미지 보정. 기절 후에는 살아 있는 대기 포켓몬이 자동으로 등장합니다.
- 배틀 화면: 풀밭과 플랫폼을 그린 장면, 상대 정면·플레이어 후면 스프라이트 경로, 포켓몬별 상태창, 하단 행동 메뉴와 최근 메시지, 펼쳐 보는 전투 기록, HP·공격·기절·등장 애니메이션. National Dex 번호를 사용해 `public/sprites/front/{번호}.png`, `back/{번호}.png`를 찾고 로딩에 실패하면 고유한 픽셀 패턴과 미제공 안내를 표시합니다.
- 특성·도구는 발동 시점별 선언형 효과로 처리합니다. 예: 위협, 정전기, 맹화, 멀티스케일, 타입 무효, 날씨에 따른 스피드, 먹다남은음식, 타입·물리·특수 기술 위력 도구. 각 항목의 편성 화면 설명에 이번 버전에서 적용되는 효과를 적었습니다.
- 날씨: 쾌청·비의 불꽃/물 데미지 보정, 모래바람의 턴 종료 피해. 필드: 일렉트릭·그래스·사이코의 해당 기술 위력 보정, 그래스필드 회복, 일렉트릭필드 잠듦 방지. 현재 지면 판정은 비행타입 여부로 단순화했습니다.
- CPU는 예상 피해, 상태·보조 기술, 교체 상황을 점수화하는 기본 AI입니다. 난수는 시드가 있는 전투 상태에 보관하므로 같은 초기 상태와 행동을 재현할 수 있습니다.
- 팀은 현재 브라우저의 `localStorage`에 버전 정보와 함께 저장됩니다. 다른 기기·브라우저와 동기화되지는 않습니다.

## 이번 버전에서 빠진 규칙

온라인 대전, 모든 세대의 합법적인 기술 조합 검사, 테라스탈, 설치기, 다단 공격, 풀죽음, 턴 종료/교체의 세부 예외 규칙은 구현하지 않았습니다. `방어`의 연속 사용 성공률 감소와 구애스카프의 기술 고정도 적용되지 않습니다. 일부 특성(까칠한피부·싱크로·이상한비늘·하늘의은총 등)은 편성 화면에 **이번 버전에서 효과 미지원**이라고 표시합니다. 눈 날씨와 미스트필드 등은 엔진에서 상태로 표현할 수 있지만 초기 기술 목록에는 모든 설정 기술을 제공하지 않습니다. 공식 Pokémon Champions 또는 Pokémon Showdown과 결과가 다를 수 있습니다.

## 스프라이트 권리와 대체 그래픽

현재 배포본에는 Pokémon 캐릭터 스프라이트 파일을 넣지 않았습니다. [Showdown 스프라이트 저장소](https://github.com/smogon/sprites#license)는 캐릭터 그림이 Nintendo·Game Freak·The Pokémon Company 소유라고 밝히고 사용 전 허가를 요청합니다. [PokeAPI 스프라이트 저장소](https://github.com/PokeAPI/sprites/blob/master/LICENCE.txt)도 이미지 저작권은 Pokémon Company에 남아 있고 제3자 권리를 정리하지 않는다고 명시합니다. [Pokémon 공식 지원 안내](https://support.pokemon.com/hc/en-us/articles/360000634094-Can-I-use-Pok%C3%A9mon-images-or-materials)는 프로젝트에서 Pokémon IP를 사용하거나 연관 짓지 말아 달라고 합니다. 따라서 확인된 사용 허가가 없는 공식 스프라이트를 복제하지 않고, National Dex 번호 기반의 로컬 파일 연결과 종별 픽셀 대체 패턴을 구현했습니다. 프로젝트에 사용 권한이 있는 이미지가 있다면 `public/sprites/README.md`의 경로에 두면 됩니다.

## 구조

| 위치 | 역할 |
| --- | --- |
| `src/data/` | 포켓몬·기술·특성·도구·성격·타입 상성 및 National Dex 번호. UI 로직과 분리된 확장 지점 |
| `src/team/` | 기본 팀, 능력치 계산, 유효성 검사, 저장·불러오기 |
| `src/engine/` | 순수 전투 상태, 행동 처리, 데미지·효과·난수·CPU AI |
| `src/App.tsx`, `src/styles.css` | 화면 및 반응형 표시. 전투 규칙은 엔진에서 처리 |
| `src/data/sprites.ts`, `public/sprites/` | 정면·후면 로컬 스프라이트 경로와 미제공 대체 화면 |
| `src/**/*.test.ts(x)` | 전투 규칙, 팀 저장·검증, UI 흐름 자동 테스트 |
| `scripts/browser-smoke.mjs` | 실제 브라우저의 메인·팀 편성·싱글·더블·모바일 화면 검사 |

향후 서버 대전을 붙일 때는 UI가 행동을 서버에 전달하고, 서버가 엔진의 상태 전이를 실행·검증하도록 확장할 수 있습니다. 현재 전투는 브라우저 안에서만 진행됩니다.

## Pokémon Showdown 검토와 출처

[Pokémon Showdown 시뮬레이터](https://github.com/smogon/pokemon-showdown/blob/master/sim/SIMULATOR.md)는 스트림·프로토콜 기반 API를 제공하고, [팀 포맷 문서](https://github.com/smogon/pokemon-showdown/blob/master/sim/TEAMS.md)는 `Teams.pack`을 설명합니다. [@pkmn/sim](https://www.npmjs.com/package/@pkmn/sim)은 타입과 브라우저 실행을 지원하는 패키지입니다. 따라서 기존 엔진을 브라우저에 통합하는 경로는 실제로 존재합니다. 이 첫 버전은 편성 데이터·전투 프로토콜·UI 상태를 연결하는 별도 어댑터 없이 작은 규칙 집합을 일관되게 플레이·테스트하기 위해 자체 엔진을 사용합니다. 향후 완전한 규칙 호환성이 목표라면 Showdown 기반 어댑터로 교체하는 것이 적절합니다.

[Pokémon Showdown 소프트웨어 라이선스는 MIT](https://github.com/smogon/pokemon-showdown/blob/master/LICENSE)입니다. 이 프로젝트는 그 소스 코드·그래픽·음악을 포함하지 않습니다. 포켓몬 이름과 관련 상표는 각 권리자에게 속합니다. 게임 화면의 캐릭터 표시는 CSS로 만든 오리지널 임시 그래픽입니다.
