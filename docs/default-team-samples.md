# 기본 팀 샘플 근거

이 게임은 여러 세대의 기술과 기믹을 함께 쓰는 자체 규칙이다. 아래 여섯 세트는 경쟁 배틀 샘플을 출발점으로 삼고, 게임에서 실제로 지원하는 기술과 도구에 맞췄다. 기본 제한은 초전설·환상 합계 4마리이며 싱글과 더블에서 선택할 수 있다.

| 포켓몬 | 역할과 기본 선택 | 참고 |
| --- | --- | --- |
| 미라이돈 | 겁쟁이, 구애안경, 특공·스피드 252. 라이트닝드라이브·용성군·오버히트·볼트체인지로 공격과 교체를 겸한다. | [Smogon Miraidon](https://www.smogon.com/dex/sv/pokemon/miraidon/) |
| 버드렉스 흑마 | 겁쟁이, 기합의띠, 특공·스피드 252. 아스트랄비트·사이코쇼크·나쁜음모·방어를 사용한다. | [Smogon Calyrex-Shadow](https://www.smogon.com/dex/sv/pokemon/calyrex-shadow/), [VGC Focus Sash](https://www.smogon.com/forums/threads/focus-sash-shadow-rider-calyrex.3742533/) |
| 자시안 왕관폼 | 명랑, 녹슨검, 공격·스피드 252. 아이언헤드는 왕관폼에서 거수참이 된다. 치근거리기·인파이트·칼춤을 곁들인다. | [Smogon Zacian-Crowned](https://www.smogon.com/dex/sv/pokemon/zacian-crowned/) |
| 무한다이노 | 차분, 검은진흙, HP·특방 252. 다이맥스포·화염방사·맹독·HP회복으로 버틴다. | [Smogon Eternatus](https://www.smogon.com/dex/sv/pokemon/eternatus/) |
| 타부자고 | 조심, 먹다남은음식, 특공·스피드 252. 골드러시·섀도볼·나쁜음모·HP회복을 사용한다. | [Smogon Gholdengo](https://www.smogon.com/dex/sv/pokemon/gholdengo/) |
| 메가루카리오 Z | 겁쟁이, 루카리오나이트 Z, 특공·스피드 252. 파동탄·러스터캐논·악의파동·나쁜음모를 고른 특수형이다. 메가루카리오 Z의 빠른 행동 성향은 [공식 소개](https://legends.pokemon.com/en-ca/news/mega_lucario_z)를 참고했다. 나머지는 이 게임의 폼 종족값과 지원 기술에 맞춰 구성했다. | [공식 메가루카리오 Z 소개](https://legends.pokemon.com/en-ca/news/mega_lucario_z) |

각 세트의 남는 노력치 4는 내구 또는 스피드에 배분했다. 네 초전설을 모두 팀에 넣기 위해 이 게임의 기본 제한을 4마리로 설정했다. 상대와의 배틀 선출에서는 싱글 3마리, 더블 4마리를 고른다.
