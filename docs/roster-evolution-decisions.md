# 최종 진화형 로스터

현재 배틀 도감 180종은 프로젝트에 포함된 `work/sprite-supplement/pokemon_species.csv`의 진화 관계를 검사해 중간 진화형이 없도록 구성했습니다. `scripts/generate-roster.cjs`는 같은 카탈로그에서 진화 단계 검사를 실행하며, 중간 단계가 다시 들어오면 데이터 생성을 실패시킵니다.

| 이전 도감 항목 | 최종형 또는 편성 조정 | 선택 이유 |
| --- | --- | --- |
| 럭키 (Chansey) | 해피너스 (Blissey) 계열을 유지하고 링곰 (Ursaluna) 추가 | 이미 있던 해피너스와 중복되는 슬롯을 강한 노말 타입 최종형으로 채움 |
| 이브이 (Eevee) | 님피아 (Sylveon) 계열 유지, 키키링 (Farigiraf) 추가 | 이브이의 최종형은 모두 종족값 합계 525. 페어리 공격과 특수 내구 활용이 쉬운 님피아를 유지하고 중복 슬롯은 노말 최종형으로 교체 |
| 피카츄 (Pikachu) | 라이츄 (Raichu) 유지, 제라오라 (Zeraora) 추가 | 라이츄와 중복되는 슬롯을 더 빠르고 강한 전기 타입 최종형으로 교체 |
| 폴리곤2 (Porygon2) | 폴리곤Z (Porygon-Z) 유지, 아르세우스 (Arceus) 추가 | 기존 폴리곤Z와 중복되는 슬롯을 높은 종족값의 노말 타입 최종형으로 교체 |
| 성원숭 (Primeape) | 저승갓숭 (Annihilape) | 최종 진화형. 공격 종족값 115, 격투/고스트 타입 |
| 코뿌리 (Rhydon) | 거대코뿌리 (Rhyperior) 유지, 디안시 (Diancie) 추가 | 기존 거대코뿌리와 중복되는 슬롯을 바위 타입 최종형으로 교체 |
| 무우마 (Misdreavus) | 무우마직 (Mismagius) 계열 유지, 기라티나 (Giratina) 추가 | 기존 최종형과 중복되는 슬롯을 고성능 고스트 타입 최종형으로 교체 |
| 미라몽 (Dusclops) | 야느와르몽 (Dusknoir) 유지, 루나아라 (Lunala) 추가 | 기존 최종형과 중복되는 슬롯을 고성능 고스트 타입 최종형으로 교체 |
| 절각참 (Bisharp) | 대도각참 (Kingambit) | 최종 진화형. 공격 135와 방어 120의 역할을 살려 다크 타입 대표로 선택 |
| 삐삐 (Clefairy) | 픽시 (Clefable) 유지, 마기아나 (Magearna) 추가 | 기존 최종형과 중복되는 슬롯을 강한 페어리/강철 최종형으로 교체 |

분기 진화는 단순히 이름이 먼저인 폼을 고르지 않습니다. 종족값, 타입 조합, 현재 엔진이 지원하는 특성과 기술을 함께 비교합니다. 예를 들어 스라크 계열은 핫삼과 사마자르가 종족값 합계 500으로 같지만, 현재 로스터의 지원 기술과 테크니션·강철 타입 조합을 쓸 수 있는 핫삼을 선택했습니다.

위 교체 종을 포함한 정면·후면 스프라이트는 기존에 기록한 PokeAPI 출처·저작권 고지를 유지하면서 로컬 파일 HTTP 응답, PNG 서명, 브라우저 디코딩, 도감 번호/종 식별자를 다시 확인합니다. 세부 결과는 `outputs/sprite-supplement-all.json`과 `public/sprites/attribution.json`에서 확인할 수 있습니다.
