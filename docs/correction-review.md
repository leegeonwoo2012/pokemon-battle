## 검사 중 발견하고 수정한 문제

- 체격 검사에서 같은 종을 팀에 두 번 넣어 기본 팀으로 되돌아가던 테스트를 수정했다. 실제 화면의 종 ID도 검사한다. 에리본/어써러셔가 라이츄로 표시된 과거 검사 결과를 성공 증거로 사용하지 않는다.
- 유효한 Z변화 기술이 도발 중 사용 불가로 판정되던 공통 검증 함수를 수정하고 실제 턴 검사로 확인했다.
- 표준 패드의 A 버튼을 길게 누르면 다음 메뉴까지 선택되던 입력 상태를 메뉴 변경 중에도 유지한다.
- 팀 준비 전 재접속의 미정의 프로필을 처리하고 배틀 시작 후 팀 교체 요청을 서버에서 거절한다.
- CPU 전장 기술의 아군/상대 표현과 친선전 게스트의 전장 메시지·기록 시점을 바로잡았다. 서버 상태와 포켓몬 이름은 수정하지 않는다.

## 남는 차이와 범위

- 정적 2D 이미지와 자체 CSS/WAAPI 효과다. 모든 종의 동작별 프레임, 같은 화풍의 그림, 3D 모델·카메라·원본 음악은 구현하지 않았다. 신장 보정은 화면 가독성을 위해 압축한 근사치이며 실제 미터 비례가 아니다.
- 전체 Showdown/공식 게임 엔진은 아니다. 미지원 특성·전용기와 대타출동·중력·강제 교체·지연 공격 등의 세부 규칙은 README의 지원 범위에 명시한다. 이번 변경으로 모든 공식 규칙이 완성됐다고 주장하지 않는다.
- CPU는 상황별 점수 모델이다. 학습형 상대 예측은 없다. CPU와 친구 친선 모두 싱글/더블을 지원하며, 배틀 진입 전에 출전 포켓몬과 대전 형식을 보여주는 시작 연출을 거친다. 친선 더블은 양쪽 2마리 이상이 필요하다.
- 서버 재시작 뒤 영구 복구, 계정·매칭·공개 인터넷 호스팅은 없다. 방은 메모리에 유지되며 연결 단절 후 2분 동안 복구 가능하다.
- 실제 외부 PC의 LAN 연결과 물리 게임패드는 검사하지 않았다. 실제 Chrome 두 참가자와 브라우저 입력 에뮬레이션으로 검사했다.
- 현재 실행 환경의 기본 8787 포트는 점유돼 있어 기본 서버 시작은 명확한 안내 후 종료했다. 기존 서버 CMD에서 Ctrl+C 후 재시작해야 최신 프로토콜을 사용한다. 기존 프로세스를 임의로 종료하지 않았다.
