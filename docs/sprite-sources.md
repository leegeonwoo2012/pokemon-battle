# Sprite source review

Reviewed 2026-10-09. All 270 current-roster species / 540 front-and-back PNGs are present in public/sprites and indexed. The current roster uses 50 PMDCollab species and 220 PokeAPI species. Ten older species pairs remain in the directory outside the current manifest.

- PokeAPI/sprites, https://github.com/PokeAPI/sprites: its README explicitly recommends downloading sprites for applications. The documented default paths are `sprites/pokemon/{NationalDex}.png` and `sprites/pokemon/back/{NationalDex}.png`. This project's 220 current-roster supplemental species use these unmodified PNGs at pinned commit `35fdbe9bdec8f519f882c3edc3c0185f08af4d86`. The repository notice is CC0 1.0 and explicitly identifies image copyright as The Pokémon Company; it is not a claim that character artwork is public domain. Preserve the full LICENCE.txt in public/sprites/licenses/.
- smogon/sprites, https://github.com/smogon/sprites#license: identifies the Pokémon rights holders and asks users to request permission; community sprite license is not clearly established there.
- PMDCollab/SpriteCollab, https://github.com/PMDCollab/SpriteCollab: the README submission/use policy and LICENSE.md grant CC BY-NC 4.0 reuse for credited community works. Official CHUNSOFT entries also occur. Each selected entry was inspected in tracker.json and credits.txt. Same-species child entries named exactly Alternate / Alternate N are alternative community drawings, not regional/Mega/shiny forms. The directory retains 52 credited species; 50 belong to the current roster. All selected source atlases returned HTTP 200 image/png and decoded.
- TheArtificial/pokemon-icons, https://github.com/TheArtificial/pokemon-icons: original fan icons exist, but no explicit reuse license was located in its README or published gallery. Public accessibility alone is not sufficient to claim permission.
- Pokémon support, https://support.pokemon.com/hc/en-us/articles/360000634094-Can-I-use-Pok%C3%A9mon-images-or-materials: asks users not to use Pokémon IP in a project.

## Reproducible inspection

- Community source commit: `47e5b9920bc5b2b491c53b18076300dc6813f103`. Its 52 species retain their original images, author credits and CC BY-NC 4.0 terms.
- Initial new-source pilot: Pikachu #25, Blastoise #9, Garchomp #445, Gengar #94, Aromatisse #683. Its 10/10 local front/back files passed at the earlier 180-species stage. Expansion pilot: Flareon #136, Incineroar #727, Rillaboom #812, Kyurem #646 and Gholdengo #1000. Their current front/back files passed 10/10 local HTTP, decoding and identity checks, and the 10 source URLs returned HTTP 200 image/png.
- Supplemental acquisition validates PNG signatures, actual Chrome decoding, dimensions and nontransparent content before writing a complete pair. National Dex identity is checked against PokeAPI's own species catalog, with pinned source and hash retained. Earlier 180-species acquisition recorded 261 HTTP requests, all HTTP 200; the expansion reports are in outputs/sprite-supplement-pilot.json and outputs/sprite-supplement-all.json.
- Baseline: 52/180 front and back, 256 absent files. Missing species were excluded by the earlier community-only collector; no image URL was indexed. Vite returned 200 text/html for their absent local paths. There was no recorded incorrect URL, filename case, bad ID or blocked request for these species. Per-species original paths, source and successful loading results plus all 128 missing species are in outputs/sprite-baseline-52.md/json.
- Current full local audit: 270 unique IDs / National Dex numbers, 540 paths, 540 decoded PNGs with correct name/Dex/source-file hash, 0 missing or failed. Every local request returned 200 image/png. The real roster UI also displays 270 front images, 0 fallback images and 0 mismatched Dex routes.
- Community atlases use first Idle frames from row 0 (South/front) and row 4 (North/back). Supplemental PokeAPI images are unchanged. They have different visual proportions; no replacement species or mirrored front picture is used for a back sprite.
- outputs/sprite-supplement-pilot-local.json and sprite-audit.json record actual HTTP status, MIME, bytes, decoded dimensions, hashes, source URLs, UI rendering counts and failure classes. Supplemental download results are in sprite-supplement-all.json. Individual attribution and full source notices remain in public/sprites.

Runtime verifies responses and cached blobs, rejects wrong species/facing paths, supports a Vite deployment base and records loading errors. A persistent cursor which previously suppressed a recovered identical URL was removed; rendering now uses the first currently verified source. Pending checks show a loading indicator. Explicit SVG and same-species front fallbacks only apply when a needed source fails verification, and never count as successful back files. The asset checker now finds 540 valid indexed files. A renamed user PNG's visual identity or rights cannot be certified solely by its filename.
